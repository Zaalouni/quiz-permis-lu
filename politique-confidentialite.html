1. Responsable du traitement

Le site Quiz Code de la Route Luxembourg (ci-après "le Site") est édité par une personne physique.

Contact : knaf2009@gmail.com

2. Données collectées

a) Données stockées localement (localStorage)

Les données suivantes sont stockées uniquement sur votre appareil et ne sont jamais transmises à nos serveurs :

  • Prénom (optionnel) — pour personnaliser l'affichage
  • Historique des quiz — scores, dates, catégories pour vos statistiques
  • Code de licence — pour maintenir l'accès premium entre les sessions
  • Préférence cookies — votre choix d'accepter ou refuser les cookies analytiques

Vous pouvez supprimer ces données à tout moment via le bouton "Réinitialiser les statistiques" ou en effaçant les données du site dans votre navigateur.

b) Données du classement (leaderboard)

Si vous choisissez de publier votre score, les données suivantes sont envoyées et stockées sur notre serveur (Cloudflare Workers KV) :

  • Prénom ou pseudonyme saisi
  • Score et nombre total de questions
  • Date de soumission
  • Type de quiz (normal ou examen)

Base légale : votre consentement (action volontaire de cliquer "Publier").

Durée de conservation : 12 mois, puis suppression automatique.

Ces données sont visibles publiquement dans le classement. Pour demander la suppression de votre score, contactez-nous par email.

c) Cookies et traceurs analytiques

Le Site utilise Google Analytics (via Google Tag Manager) pour mesurer l'audience. Ces cookies ne sont activés qu'après votre consentement explicite via la bannière affichée lors de votre première visite.

Si vous refusez, aucun cookie analytique n'est déposé et aucune donnée n'est transmise à Google.

Cookies déposés en cas d'acceptation :

  • _ga — identifiant anonyme (durée : 2 ans)
  • _ga_* — état de session (durée : 2 ans)

Base légale : votre consentement (Art. 6(1)(a) RGPD).

Vous pouvez retirer votre consentement à tout moment en effaçant les cookies de votre navigateur.

3. Destinataires des données

  • Google LLC (États-Unis) — analytics, si consentement donné. Transfert encadré par les clauses contractuelles types de la Commission européenne.
  • Cloudflare Inc. (États-Unis) — hébergement du serveur API (classement, licences). Transfert encadré par les clauses contractuelles types.
  • GitHub Inc. (États-Unis) — hébergement du Site (GitHub Pages). Transfert encadré par les clauses contractuelles types.

4. Vos droits

Conformément au RGPD (Règlement UE 2016/679), vous disposez des droits suivants :

  • Accès — obtenir une copie de vos données
  • Rectification — corriger des données inexactes
  • Effacement — demander la suppression de vos données
  • Limitation — restreindre le traitement
  • Portabilité — recevoir vos données dans un format structuré
  • Opposition — vous opposer au traitement

Pour exercer ces droits, contactez : knaf2009@gmail.com

Vous avez également le droit d'introduire une réclamation auprès de la CNPD (Commission Nationale pour la Protection des Données) :
15, Boulevard du Jazz, L-4370 Belvaux, Luxembourg — cnpd.public.lu

5. Sécurité

Nous mettons en place des mesures techniques appropriées : communications chiffrées (HTTPS), accès restreint aux données, hébergement chez des fournisseurs certifiés.

6. Modifications

Cette politique peut être mise à jour. La date de dernière modification est indiquée en haut de page.

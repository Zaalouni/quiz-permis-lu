Comprendre les distances de freinage

La distance d'arrêt est l'un des sujets les plus importants de l'examen théorique au Luxembourg. Elle se compose de deux éléments : la distance de réaction et la distance de freinage.

Les formules essentielles

  • Distance de réaction = (Vitesse / 10) x 3 mètres
  • Distance de freinage (sec) = (Vitesse / 10)² mètres
  • Distance de freinage (mouillé) = Distance freinage x 2
  • Distance d'arrêt = Distance de réaction + Distance de freinage

Pièges fréquents à l'examen

Les questions portent souvent sur la route mouillée (distance x2), le temps de réaction allongé (fatigue, alcool, téléphone) et la différence entre distance de freinage et distance d'arrêt. Retenez : la distance d'arrêt inclut toujours le temps de réaction.

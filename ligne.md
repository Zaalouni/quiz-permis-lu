# LIGNES & MARQUAGES AU SOL — Luxembourg
## Préparation Examen Théorique SNCA + Pièges

> Sources officielles : transports.public.lu (Art. 110 Code de la route) | police.public.lu | legilux.public.lu
> Dernière mise à jour : mars 2026

---

## PRINCIPE FONDAMENTAL (Art. 110 & 112 Code de la route LU)

> *"Le marquage sur la voie, encore appelé signalisation horizontale, s'utilise seul ou en complément des signaux routiers pour guider le conducteur ou délimiter des espaces à caractéristiques particulières. Les usagers doivent s'y conformer."*

**Deux couleurs au Luxembourg :**
- **BLANC** = marquage permanent (normal)
- **JAUNE** = marquage permanent spécifique (stationnement, chantier) — **le jaune prime toujours le blanc en cas de conflit**

## BLOC 1 — LIGNES LONGITUDINALES (dans le sens de la route)

Ces lignes séparent les voies ou délimitent les bordures.

---

### 1.1 Ligne axiale discontinue blanche — "Trait pointillé central"

```
- - - - - - - - - - - -
```

| Élément | Détail |
|---|---|
| Couleur | Blanche |
| Forme | Segments courts (tirets courts, espaces longs) |
| Emplacement | Centre de chaussée bidirectionnelle |
| Signification | Séparation des 2 sens de circulation |
| Dépassement autorisé | OUI si visibilité suffisante |
| Franchissement | OUI (pour dépasser, tourner) |
| Stationnement en contresens | **OUI autorisé au Luxembourg** si ligne axiale discontinue |

**Spécificité luxembourgeoise :** Les voitures peuvent stationner en contresens dans une rue à double sens **si la ligne axiale est discontinue**.

---

### 1.2 Ligne de sécurité continue blanche — "Ligne pleine centrale"

```
————————————————————————
```

| Élément | Détail |
|---|---|
| Couleur | Blanche |
| Forme | Ligne ininterrompue |
| Emplacement | Centre de chaussée, virages, zones dangereuses |
| Signification | Interdiction de franchir, dépasser ou changer de voie |
| Dépassement | **INTERDIT** (même pour dépasser un cycliste) |
| Franchissement | **INTERDIT** sauf urgence absolue |

> Art. 110 CdR LU : *"Lignes de sécurité longitudinales continues qui interdisent le dépassement ou le passage d'une voie à une autre."*

---

### 1.3 Ligne mixte (continue + discontinue) — "Ligne mixte"

```
————————————— - - - - -
```

| Élément | Détail |
|---|---|
| Couleur | Blanche |
| Forme | Continue d'un côté, discontinue de l'autre |
| Signification | Chaque conducteur respecte la ligne de SON côté |
| Si ligne continue à votre gauche | **Dépassement interdit** pour vous |
| Si ligne discontinue à votre gauche | **Dépassement autorisé** pour vous (si voie libre) |

**Règle d'or :** regardez la ligne du côté de votre véhicule, pas celle d'en face.

---

### 1.4 Ligne de dissuasion discontinue blanche — "Traits longs"

```
——————   ——————   ——————
```

| Élément | Détail |
|---|---|
| Couleur | Blanche |
| Forme | Segments longs (plus longs que les tirets normaux) |
| Signification | Dépassement déconseillé mais non interdit |
| Utilisation | Zones où la visibilité est réduite mais pas nulle |
| Franchissement | **Autorisé mais prudence maximale requise** |

---

### 1.5 Ligne de rive blanche — "Bord de chaussée"

```
Chaussée | _______________| Accotement
```

| Élément | Détail |
|---|---|
| Couleur | Blanche |
| Forme | Continue ou discontinue selon le contexte |
| Emplacement | Bord droit de la chaussée |
| Continue | Accotement **non praticable** — interdit de le franchir |
| Discontinue | Accotement praticable temporairement (stationnement d'urgence) |
| Autoroute | Sépare la chaussée de la **bande d'arrêt d'urgence** |

---

### 1.6 Ligne jaune continue sur bordure/trottoir — "Jaune plein"

```
Trottoir [══════════════════] Chaussée
```

| Élément | Détail |
|---|---|
| Couleur | **Jaune** |
| Forme | Continue, sur ou contre le bord du trottoir/chaussée |
| Signification | **Stationnement INTERDIT** |
| Arrêt autorisé ? | **NON** — arrêt ET stationnement interdits |
| Amende LU | **49 €** (arrêt) à **145 €** (stationnement gênant) |

> Art. 110 CdR LU : *"Lorsque le marquage est jaune et sous forme de lignes continues sur les bordures d'un trottoir ou d'une chaussée, il indique l'interdiction d'y stationner."*

---

### 1.7 Ligne jaune discontinue sur bordure — "Jaune pointillé"

```
Trottoir [- - - - - - - - -] Chaussée
```

| Élément | Détail |
|---|---|
| Couleur | **Jaune** |
| Forme | Discontinue (tirets) sur ou contre la bordure |
| Signification | **Stationnement INTERDIT** — arrêt court autorisé |
| Arrêt autorisé ? | **OUI**, pour déposer/prendre passager ou marchandise (brève durée, conducteur ne quitte pas le véhicule ou reste à proximité) |
| Stationnement | **NON** |

---

### 1.8 Marquage jaune chantier — "Jaune temporaire"

| Élément | Détail |
|---|---|
| Couleur | **Jaune** |
| Contexte | Zone de travaux |
| Règle | **Prime le marquage blanc** existant |
| Obligation | Suivre le marquage jaune même si le blanc indique autre chose |

## BLOC 2 — LIGNES TRANSVERSALES (perpendiculaires à la route)

Ces lignes indiquent des points d'arrêt ou de cession de priorité.

---

### 2.1 Ligne d'arrêt blanche (STOP) — "Trait large perpendiculaire"

```
||||||||||||||||||||||||||||||| ← large bande blanche
```

| Élément | Détail |
|---|---|
| Couleur | Blanche |
| Forme | Ligne large continue perpendiculaire à la chaussée |
| Signification | Arrêt complet **obligatoire** avant la ligne |
| Accompagnement | Toujours avec panneau STOP rouge (B2) |
| Obligation | Arrêter même si aucun véhicule n'arrive |
| Reprise | Reprendre uniquement si voie libre |

---

### 2.2 Dents de scie (Cédez le passage) — "Triangle de points"

```
▼ ▼ ▼ ▼ ▼ ▼ ▼ ▼ ▼
```

| Élément | Détail |
|---|---|
| Couleur | Blanche |
| Forme | Lignes ou marques triangulaires (dents de scie) perpendiculaires à l'axe |
| Signification | Cédez le passage — ralentir, **s'arrêter si nécessaire** |
| Accompagnement | Panneau cédez le passage (B1) ou triangle renversé |
| Différence STOP | Pas d'arrêt obligatoire si voie libre |

> Art. 110 CdR LU : *"Lignes ou marques en dents de scie qui indiquent la ligne à ne pas franchir lorsqu'ils doivent céder le passage."*

---

### 2.3 Passage pour piétons — "Zèbres"

```
|   |   |   |   |   |   |
```

| Élément | Détail |
|---|---|
| Couleur | Blanche |
| Forme | Bandes larges parallèles à l'axe de la chaussée |
| Signification | Zone prioritaire pour les piétons |
| Obligation conducteur | Céder le passage au piéton qui s'engage **ou manifeste l'intention** de traverser |
| Arrêt/stationnement | **Interdit** sur et à moins de **5 m avant** le passage |
| Amende LU | 49 € (stationnement) |

## BLOC 3 — MARQUAGES SPÉCIAUX ET ZONES

---

### 3.1 Rectangle blanc au sol — "Place de stationnement"

```
┌─────────────────┐
│                 │
└─────────────────┘
```

| Élément | Détail |
|---|---|
| Couleur | Blanche |
| Forme | Rectangle délimitant un emplacement |
| Signification | **Stationnement autorisé** dans les limites du rectangle |
| En zone résidentielle | Seuls les emplacements rectangles blancs (ou panneau E9) permettent de stationner |

---

### 3.2 Zébras (hachures obliques) — "Zone interdite"

```
/////////////////////
/////////////////////
```

| Élément | Détail |
|---|---|
| Couleur | Blanche (ou jaune) |
| Forme | Bandes obliques remplissant une surface |
| Signification | Zone où **arrêt et stationnement sont interdits** |
| Localisation | Devant sorties de secours, zones de manœuvre, carrefours |
| Circulation | Permise si nécessaire pour traverser |

---

### 3.3 Croix diagonale au sol — "X sur l'emplacement"

```
╲   ╱
 ╲ ╱
 ╱ ╲
╱   ╲
```

| Élément | Détail |
|---|---|
| Couleur | Jaune ou blanche |
| Forme | Deux lignes diagonales en croix |
| Signification | **Arrêt, stationnement et arrêt prolongé interdits** |
| Contexte | Souvent associé à "LIVRAISONS" ou "BUS" |
| Amende LU | 49 € à 145 € selon gravité |

---

### 3.4 Ligne zigzag jaune — "Arrêt de bus"

```
/\/\/\/\/\/\/\/\/\/\
```

| Élément | Détail |
|---|---|
| Couleur | **Jaune** |
| Forme | Zigzag sur la chaussée |
| Signification | **Zone d'arrêt de bus** |
| Pour autres véhicules | **Arrêt interdit** pendant les heures de service |
| Si délimitation au sol | La limite au sol est **prioritaire sur la distance des 15 m au panneau** |
| Stationnement | **Interdit** — amende 49 € (LU : catalogue art. 107-37) |

---

### 3.5 Flèches de présélection — "Flèches directionnelles"

```
  ↑     ↑↗     ↗
```

| Élément | Détail |
|---|---|
| Couleur | Blanche |
| Forme | Flèche(s) peintes dans la voie |
| Signification | Direction **obligatoire** ou présélectionnée pour cette voie |
| Obligation | Suivre la direction indiquée |
| Changement de voie | Possible avant la flèche, **interdit dessus** |

---

### 3.6 Marquage "BUS" au sol — "Voie réservée bus"

| Élément | Détail |
|---|---|
| Couleur | Blanche |
| Signification | Voie réservée aux bus |
| Autres véhicules | **Interdit** sauf autorisation par panneau ou marquage |
| Cyclistes | Autorisés sur voies bus **uniquement si panneau** le précise |
| Damier bus (noir/blanc) | Marquage aux carrefours facilitant le passage des bus |

---

### 3.7 Bande d'arrêt d'urgence (BAU) — Autoroute

| Élément | Détail |
|---|---|
| Délimitation | Ligne de rive blanche continue |
| Usage autorisé | Panne, urgence médicale, force majeure uniquement |
| Stationnement | **Strictement interdit** |
| Circulation | **Interdite** — sauf formation du couloir de secours |
| Couloir de secours | **Autorisé** de se placer sur la BAU pour libérer le passage |

## BLOC 4 — RÉCAPITULATIF COULEURS ET SIGNIFICATIONS

| Couleur | Forme | Signification |
|---|---|---|
| Blanche | Continue axiale | Dépassement/franchissement **INTERDIT** |
| Blanche | Discontinue axiale | Dépassement **AUTORISÉ** si sécurité |
| Blanche | Mixte | Respecter la ligne de **son côté** |
| Blanche | Dents de scie | **Céder le passage** (s'arrêter si nécessaire) |
| Blanche | Bande large transversale | **STOP** — arrêt absolu obligatoire |
| Blanche | Zèbres | Passage piétons — **priorité piétons** |
| Blanche | Rectangle | **Stationnement autorisé** |
| Blanche | Hachures obliques | **Arrêt + stationnement interdits** |
| **Jaune** | Continue bordure | **Stationnement INTERDIT** — arrêt interdit aussi |
| **Jaune** | Discontinue bordure | **Stationnement INTERDIT** — arrêt court autorisé |
| **Jaune** | Zigzag chaussée | **Arrêt interdit** (zone bus) |
| **Jaune** | Croix diagonale | **Arrêt + stationnement + arrêt prolongé interdits** |
| **Jaune** | Temporaire chantier | **Prime le blanc** — à suivre en priorité absolue |

## BLOC 5 — PIÈGES SNCA — LIGNES ET MARQUAGES

---

### PIÈGE 1 — Ligne jaune continue : arrêt autorisé ou non ?
❌ **Faux cru :** "Ligne jaune continue = stationnement interdit mais arrêt OK"
✅ **VRAI :** Ligne jaune **continue** sur bordure = **stationnement ET arrêt interdits**. C'est la ligne jaune **discontinue** qui autorise l'arrêt bref.

---

### PIÈGE 2 — Stationnement en contresens : légal au Luxembourg ?
❌ **Faux cru :** "Stationner en contresens est toujours interdit"
✅ **VRAI :** Au Luxembourg, **autorisé en rue à double sens si la ligne axiale est discontinue**. C'est une spécificité luxembourgeoise absente dans la plupart des autres pays.

---

### PIÈGE 3 — Jaune chantier vs blanc permanent : lequel respecter ?
❌ **Faux cru :** "Je suis le marquage blanc car il est permanent"
✅ **VRAI :** Le marquage **jaune chantier prime toujours le blanc**, même si les deux sont visibles en même temps.

---

### PIÈGE 4 — Ligne mixte : quel côté regarde-t-on ?
❌ **Faux cru :** "Si je vois une ligne continue devant moi, je peux dépasser si l'autre côté est discontinu"
✅ **VRAI :** Chaque conducteur respecte uniquement la ligne **de son propre côté**. Ligne continue à votre gauche = dépassement **interdit pour vous**, peu importe ce qu'il y a de l'autre côté.

---

### PIÈGE 5 — Arrêt de bus avec marquage zigzag : distance des 15 m valable ?
❌ **Faux cru :** "Je peux stationner si je suis à plus de 15 m du panneau d'arrêt de bus"
✅ **VRAI :** Si un **marquage au sol zigzag jaune** délimite la zone, c'est ce marquage qui fait foi, **quelle que soit la distance du panneau**. Si vous êtes dans la zone marquée = interdit.

---

### PIÈGE 6 — Passage piéton : à quelle distance est-il interdit de stationner ?
❌ **Faux cru :** "Juste sur le passage lui-même"
✅ **VRAI :** Interdit de stationner sur le passage **ET dans un rayon de 5 m en amont** (côté approche). L'arrêt y est également interdit.

---

### PIÈGE 7 — Dents de scie = même obligation que STOP ?
❌ **Faux cru :** "Les dents de scie imposent un arrêt complet comme le STOP"
✅ **VRAI :** Les dents de scie (cédez le passage) imposent de **ralentir et s'arrêter si nécessaire**. Si la voie est libre, on peut passer sans s'arrêter complètement. Le STOP impose lui un **arrêt absolu**, voie libre ou non.

---

### PIÈGE 8 — Voie bus : les cyclistes peuvent-ils y circuler ?
❌ **Faux cru :** "Les cyclistes sont toujours interdits sur les voies bus"
✅ **VRAI :** Les cyclistes sont **en principe interdits** sur les voies bus, **sauf si un panneau ou marquage l'autorise explicitement**.

---

### PIÈGE 9 — Bande d'arrêt d'urgence autoroute : quand l'utiliser ?
❌ **Faux cru :** "On peut s'y arrêter pour téléphoner ou se reposer"
✅ **VRAI :** La BAU est réservée aux **arrêts d'urgence non planifiés** (panne, malaise). Téléphone = **interdit**. Repos = **interdit**. Formation du couloir de secours = **autorisé et obligatoire** en cas de bouchon.

---

### PIÈGE 10 — Hachures obliques (zébras) : peut-on y circuler ?
❌ **Faux cru :** "On ne peut ni stationner ni circuler sur les hachures"
✅ **VRAI :** L'arrêt et le stationnement y sont interdits, mais **la circulation est permise** si nécessaire pour traverser la zone (ex. pour tourner).

---

### PIÈGE 11 — Flèche de présélection : peut-on changer de voie dessus ?
❌ **Faux cru :** "On peut changer de voie jusqu'au carrefour"
✅ **VRAI :** Le changement de voie est **possible avant la flèche**, mais **interdit une fois sur la flèche** peinte. La flèche engage le conducteur dans la direction indiquée.

---

### PIÈGE 12 — Rectangle blanc : autorise-t-il toujours le stationnement ?
❌ **Faux cru :** "Un rectangle blanc = je peux toujours stationner"
✅ **VRAI :** Le rectangle blanc délimite un emplacement. Mais si un **panneau additionnel** indique une restriction (durée limitée, véhicule spécifique, disque requis), ces restrictions s'appliquent **en plus** du marquage. Le rectangle seul n'est pas une autorisation inconditionnelle.

## BLOC 6 — RÉSUMÉ MÉMORISATION RAPIDE

| À retenir | Règle |
|---|---|
| Jaune continu sur bordure | Arrêt + stationnement interdits |
| Jaune discontinu sur bordure | Stationnement interdit / arrêt bref OK |
| Jaune zigzag chaussée | Zone d'arrêt bus — arrêt autres véhicules interdit |
| Jaune chantier | Prime TOUJOURS le marquage blanc |
| Blanc continu axial | Franchissement INTERDIT |
| Blanc discontinu axial | Franchissement AUTORISÉ si sécurisé |
| Blanc mixte | Respecter la ligne de SON côté |
| Dents de scie | Cédez le passage (pas d'arrêt si voie libre) |
| Bande large blanche | STOP = arrêt absolu obligatoire |
| Zèbres | Passage piétons — priorité piétons |
| Stationnement en contresens LU | Autorisé si ligne axiale discontinue |
| 5 m avant passage piétons | Arrêt + stationnement interdits |
